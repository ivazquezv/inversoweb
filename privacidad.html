Política de Privacidad

Información sobre el uso de datos en IN VERSO

Esta Política de Privacidad describe cómo se recopila, utiliza y protege la información personal de los usuarios que visitan el sitio web de IN VERSO. Este proyecto no está actualmente activo como banda, pero mantiene esta web como archivo histórico y punto de referencia informativa.

1. Responsable del Tratamiento

El responsable del tratamiento de los datos es:

IN VERSO (Proyecto Musical)
Contacto: contacto@inverso.com

2. Datos que se Recopilan

Este sitio web no recopila datos personales de forma automática. Solo se recopila información si el usuario decide contactar mediante correo electrónico u otros medios proporcionados.

Los datos que pueden recopilarse son:

  • Nombre y apellidos (si el usuario los facilita)
  • Correo electrónico
  • Contenido del mensaje enviado

3. Finalidad del Tratamiento

Los datos proporcionados voluntariamente por el usuario se utilizan exclusivamente para:

  • Responder consultas o solicitudes de información
  • Gestionar comunicaciones relacionadas con el proyecto IN VERSO

4. Conservación de los Datos

Los datos se conservarán únicamente durante el tiempo necesario para responder a la consulta o mantener la comunicación iniciada por el usuario.

5. Cesión de Datos a Terceros

IN VERSO no comparte, vende ni cede datos personales a terceros. Únicamente se utilizarán servicios externos necesarios para el funcionamiento de la web (por ejemplo, hosting), los cuales cumplen con la normativa vigente.

6. Derechos del Usuario

El usuario puede ejercer los siguientes derechos:

  • Acceso a sus datos
  • Rectificación
  • Supresión
  • Limitación del tratamiento
  • Oposición

Para ejercer estos derechos, puede escribir a: contacto@inverso.com

7. Cookies y Servicios de Terceros

Este sitio web utiliza únicamente cookies técnicas necesarias para su funcionamiento. No se emplean cookies de seguimiento, analítica ni publicidad.

Algunos servicios externos utilizados por la web pueden recopilar datos técnicos, como:

  • Google Fonts (carga de tipografías)
  • YouTube (si se incrustan vídeos)

Estos servicios tienen sus propias políticas de privacidad.

8. Seguridad

Se aplican medidas razonables para proteger los datos personales frente a accesos no autorizados, pérdida o alteración.

9. Modificaciones de esta Política

IN VERSO puede actualizar esta política en cualquier momento. La fecha de la última actualización aparecerá al final del documento.

Última actualización: 2025
