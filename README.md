# IN VERSO — Web Archive  
Sitio web histórico dedicado a IN VERSO, banda española de death metal melódico / progresivo activa entre 2010 y 2016.  
Este proyecto preserva su legado musical, biográfico y artístico en formato web.

---

## 🎸 Sobre IN VERSO
IN VERSO fue una banda madrileña de metal extremo con influencias de death melódico sueco, doom atmosférico y metal progresivo.  
Su obra principal, **«Corvus Corax»**, grabada en PKO Studio y producida por Emilio Mercader, es considerada un lanzamiento de culto dentro del underground español.

El sitio web incluye:
- Biografías de los miembros
- Historia completa del proyecto
- Cronología detallada (2010–2016)
- Información del álbum «Corvus Corax»
- Material visual y documentación histórica

## 🚀 Publicación con GitHub Pages

Este repositorio puede publicarse fácilmente como sitio web estático:

1. Ir a **Settings → Pages**
2. En “Build and deployment”, seleccionar:
   - **Source:** Deploy from a branch  
   - **Branch:** `master`  
   - **Folder:** `/root`
3. Guardar

La web quedará disponible en:

https://ivazquezv.github.io/inversoweb
